CLASS TextEditor
    ATTRIBUTE: text
    ATTRIBUTE: undoStack (stack of strings)

    METHOD type(word)
        push current text into undoStack
        append word to text

    METHOD undo()
        IF undoStack is not empty
            pop from undoStack and restore text
        ELSE
            PRINT "Nothing to undo"

    METHOD show()
        PRINT current text

MAIN PROGRAM
    Create a TextEditor
    Type "Hello"
    Type " World"
    Show text  --> "Hello World"
    Undo
    Show text  --> "Hello"
